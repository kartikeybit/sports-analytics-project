# 🏅 Sports Analytics Dashboard – Power BI

## 📌 Project Overview

The Olympic Data Analysis project uses historical Olympic Games data to analyze and uncover meaningful insights about athletes, countries, sports, events, medals, participation, and Olympic seasons. The project applies data analytics and visualization techniques to identify trends in medal distribution, athlete participation, country performance, sports popularity, and the growth of the Olympic Games over time.

The dashboard provides an interactive view of Olympic performance across different years, seasons, sports, and regions.

---

## 🎯 Project Objectives

- Analyze Olympic Games participation over the years
- Compare Summer and Winter Olympic Games
- Analyze medal distribution by country
- Identify top-performing countries
- Analyze participation across different sports
- Analyze medal distribution across sports
- Analyze regional/NOC participation
- Identify countries with the highest number of participants
- Provide interactive insights using Power BI
